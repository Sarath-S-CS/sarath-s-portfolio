# Sarath Surendran Portfolio

This folder contains a static portfolio website prepared for GitHub Pages.

## Files
- `portfolio.html` — main site file

## Publish on GitHub Pages
1. Create a new public repository on GitHub.
2. Rename `portfolio.html` to `index.html`.
3. Upload `index.html` to the repository root.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/root` folder, then save.
7. GitHub will publish the site at a public read-only URL.

## Recommended repository names
- `sarathsurendran.github.io`
- `sarath-surendran-portfolio`

## Notes
- Visitors can view the site publicly, but only repository collaborators can change the content.
- Update LinkedIn, email, and experience details as your profile changes.
